## 1. System Overview

> - **Product:** AI-powered vernacular tutoring app for JEE / NEET / WB Board aspirants
> - **Primary market:** Tier-2/3 cities (Asansol, Durgapur, Bardhaman) — Bengali-first, then Hindi, Tamil, Telugu
> - **Architecture:** iOS mobile app + Python FastAPI backend + CrewAI 4-agent crew + RAG pipeline
> - **Dev LLM:** NVIDIA NIM (Sarvam-M for Indian languages, Qwen3 for agent reasoning) — free, no credit card
> - **Prod LLM:** GPT-4o mini / Claude Haiku — swap via .env only, zero code change
> - **AI tool:** GitHub Copilot + VS Code for all development (estimated 40% dev time saving)

## 2. End-to-End Architecture

### 2.1 Architecture Layers

The system has four distinct layers. Each layer communicates only with the layer directly adjacent to it.

**LAYER 1 — iOS App (Student's device)**
```
Study Screen           SwiftUI views for questions, answers, equation rendering
Voice Input            AVFoundation microphone capture -> Bhashini API (Bengali/Hindi STT)
Offline Storage        Core Data: pre-downloaded question packs, sync queue for answers
Progress Screen        Swift Charts for topic coverage, streak tracker, parent dashboard
Subscriptions          StoreKit 2: freemium gating, monthly/annual plans, family sharing
Push Notifications     APNs: daily study reminders, plateau alerts from Progress Monitor agent
Language Picker        Onboarding: student picks preferred language, stored in profile
HTTP Client            URLSession / Alamofire -> FastAPI backend (JWT auth, JSON)
```

**LAYER 2 — FastAPI Backend (Railway / Render cloud server)**
```
POST /ask              Receives student question -> routes to Question Generator agent
GET  /plan/:id         Returns today's study plan (generated by Curriculum Planner at 2 AM)
POST /sync-answers     Receives offline quiz answers -> stores in PostgreSQL
GET  /progress/:id     Returns weekly progress snapshot for parent dashboard
POST /auth/token       JWT login (email + password), refresh token logic
Background tasks       FastAPI BackgroundTasks: triggers nightly agent crew via APScheduler
Validation             Pydantic models for all request/response shapes
ORM                    SQLAlchemy 2.0 async with Alembic migrations
```

**LAYER 3 — CrewAI Agent Crew (runs inside FastAPI process)**
```
Diagnostic Agent       Reads last 7 days quiz_answers -> maps weak topics via RAG syllabus
   Tool: quiz_history_tool (SQLAlchemy query)
   Tool: syllabus_map_tool (RAG vector search)
   LLM: Qwen3-235B on NIM (dev) / GPT-4o mini (prod)

Curriculum Planner Agent  Takes diagnostic output -> generates 7-day study plan (SM-2 algorithm)
   Tool: write_plan_tool (PostgreSQL insert)
   LLM: Qwen3-235B on NIM (dev) / GPT-4o mini (prod)

Question Generator Agent  RAG search on JEE corpus -> LLM generates Bengali/Hindi explanation
   Tool: rag_search_tool (Chroma/Pinecone similarity search)
   LLM: Sarvam-M on NIM (dev) / GPT-4o mini (prod)

Progress Monitor Agent    Nightly: detects plateaus -> sends WhatsApp alert if stuck 3+ days
   Tool: progress_read_tool (PostgreSQL query)
   Tool: whatsapp_send_tool (WhatsApp Business API via MCP)
   LLM: Qwen3-235B on NIM (dev) / GPT-4o mini (prod)
```

**LAYER 4 — Data & External Services**
```
PostgreSQL             students, quiz_answers, study_plans, subscriptions, progress_snapshots
Chroma (dev)           Local vector DB. JEE/NEET/WBCHSE PDFs embedded with nv-embedqa-e5-v5
Pinecone (prod)        Managed vector DB. Same embedding model, same query API.
NVIDIA NIM (dev)       https://integrate.api.nvidia.com/v1 — Sarvam-M + Qwen3 + embeddings
OpenAI (prod)          https://api.openai.com/v1 — GPT-4o mini + text-embedding-3-small
Bhashini API           Speech-to-text + TTS for all 22 Indian languages
WhatsApp Business API  Outbound alerts from Progress Monitor agent (via MCP tool server)
Apple APNs             Push notifications triggered by FastAPI background tasks
Apple StoreKit 2       Subscription management — handled entirely on iOS side
```

### 2.2 Data Flow — One Student Query (Real-Time)

Step-by-step trace of what happens when Riya types a question in Bengali:

1. Riya types question in SwiftUI view -> taps Send
2. iOS: URLSession POST /ask with `{ student_id, question, language: 'bn' }`
3. FastAPI: validates JWT token, reads student profile from PostgreSQL (preferred_language='bn')
4. FastAPI: calls Question Generator Agent.kickoff(question, language='bn')
5. Agent: calls rag_search_tool -> embeds query with nv-embedqa-e5-v5 -> searches Chroma -> returns top-5 JEE chunks
6. Agent: calls LLM (Sarvam-M on NIM) with system prompt 'Answer in Bengali' + RAG context + student question
7. LLM streams back Bengali explanation + 2 practice problems as JSON
8. FastAPI: returns response to iOS in ~3 seconds
9. iOS: SwiftUI renders Bengali text, equation viewer for math, saves question to Core Data
10. iOS: answer stored in sync queue if offline; uploaded when wifi returns

### 2.3 Nightly Agent Cycle (2 AM Automatic)

APScheduler triggers the full crew every night. No human involved.

1. Diagnostic Agent: reads all quiz_answers from last 24h for every active student
2. Diagnostic Agent: RAG-matches wrong answers to syllabus topics -> produces weak_topics list per student
3. Curriculum Planner Agent: receives weak_topics -> applies SM-2 spaced repetition -> writes study_plans for tomorrow
4. Progress Monitor Agent: checks if any student has 3+ consecutive weak sessions on same topic
5. Progress Monitor Agent: for flagged students -> calls whatsapp_send_tool -> sends alert in student's language
6. All results written to PostgreSQL -> iOS app reads updated plan on next open

### 2.4 Multilingual Architecture

Language is a rendering preference, not a data architecture change. The same RAG corpus and agents serve all languages.

| Component | How language is handled |
|-----------|------------------------|
| Student profile | preferred_language field in PostgreSQL (ISO 639-1: 'bn', 'hi', 'ta', 'te', 'mr', 'en') |
| FastAPI | Reads preferred_language from student profile, passes to agent as task parameter |
| Agent system prompt | get_tutor_prompt(lang) returns 'Always respond in Bengali' etc. — 10 lines of Python |
| RAG corpus | Stored in English (JEE textbooks are English). LLM reads English chunks, writes answer in student's language |
| Sarvam-M (NIM) | Purpose-built for Bengali, Hindi, Marathi, Tamil, Telugu, Gujarati, Kannada, Malayalam, Odia, Punjabi |
| Bhashini API | Handles STT + TTS for all 22 scheduled Indian languages. language_code param per request |
| iOS app | NSLocalizedString + Localizable.strings per language. Language picker on onboarding screen |
| WhatsApp alerts | Progress Monitor generates alert text using same LLM + language preference. Same tool, different prompt |
